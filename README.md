# כולם לישיבת צוות! נוהל קבוצת הוואטסאפ של הכיתה

מצגת אינטראקטיבית לשיעור של 45 דקות לכיתה ה׳: הכיתה כותבת יחד נוהל (אמנה) לקבוצת הוואטסאפ הכיתתית. השיעור בנוי בהשראת הסדרה ״קופה ראשית״ (כאן 11): הכיתה היא צוות של סניף סופרמרקט, וראמזי מדריך את השיעור.

**סקיצה חינוכית לא מסחרית ולא רשמית.** השיעור לא קשור לכאן 11 או ליוצרי הסדרה ולא אושר על ידם. כל הזכויות על הדמויות, השמות והתמונות שמורות לכאן 11 (תאגיד השידור הישראלי) וליוצרי ״קופה ראשית״. הדף פורסם לצורך התייעצות בלבד, והתמונות יוסרו מיד לבקשת בעלי הזכויות.
